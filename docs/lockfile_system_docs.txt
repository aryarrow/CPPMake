This documentation is only for devs who want to use or want to contribute to the lockfile system

So here is all you need to know
./src/lockfilemgr.cpp
what does it do?
Well it contains 3 classes lockfile_reader, lockfile_writer and lockfile_mgr

lockfile_writer...why does it exist?
this exists only for one purpose to write the File class's data inside of the lock file
warning:the constructor opens the lockfile and erases it! so when creating a lockfile_writer make sure to write everything you need
UNLESS you explicitly want bugs in your code or the file erased
warning:the deconstructor is the one that ends the file with a } so dont try to parse the lockfile before finishing the write or you'll get a very nice parsing error
usage: lockfile_writer<<File*;

lockfile_reader, also why?
This is a wrapper of the lockfile class thats in ./src/lockfilesys/locker.cpp
What does it do? Well it's meant to construct File* classes from the lockfile

lockfile_mgr, why?
This is the wrapper of lockfile_reader and lockfile_writer
basically what it does it has a hash map of shared_ptr of File
and a vector of shared_ptr of File object_dummies (DONT USE THIS ONE)

./src/lockfilesys/locker.cpp
Very important one, misleading name...i know but this is the lock file PARSER
How to use:just create the thing with the default constructor and just call the parse_lock_file()
Sadly at the moment you cant use the lock file parser for any other file name other than incremental.lock...

./src/lockfilesys/tokenizer.cpp + ./src/lockfilesys/tokens.cpp
This one i recomend you actually read the code tokens.cpp only has an enum class of tokens and tokenizer.cpp
And tokenizer.cpp is just a lexer... literally its that simple take a look at the code.
The only thing it does it literally transforms the file with the tokens inside of the enum class inside tokens.cpp
Usage:tokenizer tokens{const std::string& filename};

./src/lockfilesys/variable.cpp
Okay this one is complicated for me to explain because the code is also pretty complicated.
How does it work?
It has a 4 important variables inside;
using list=std::vector<std::unique_ptr<variable>>;
using object=std::unordered_map<std::string,std::unique_ptr<variable>>;

and the last one, value_type value;
